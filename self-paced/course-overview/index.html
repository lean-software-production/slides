Where the course starts: the Ralph loop

while :; do cat PROMPT.md | claude-code done

Wake up · read the plan · do the next step · tick it off · go back to sleep ↺

⏱ 00:02–00:03 · 1 min
🎤 Matt
  • Matt: Geoffrey Huntley's post “Ralph Wiggum as a ‘software engineer’” (July 2025, ghuntley.com/ralph): a Bash loop that starts a coding agent again and again with the same prompt. He showed that you don't need something complicated to get something powerful, and it got round the context window problem.
  • It's named after Ralph Wiggum from The Simpsons: well-meaning, but maybe not all that bright. Each time round, a new agent session wakes up, looks at the plan, does the next step, ticks it off and goes back to sleep. No single session has to think very hard.
  • It isn't where software factories started. It's where this course starts: the small idea at the heart of everything that follows, and the first bike you ride, a little kid's bike.
  • “The factory you'll build grows from this.” Hand to David.
