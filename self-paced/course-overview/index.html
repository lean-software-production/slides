Where it started: the Ralph loop

while :; do cat PROMPT.md | claude-code done

Wake up · read the plan · do the next step · tick it off · go back to sleep ↺

⏱ 00:02–00:03 · 1 min
🎤 Aldric
  • Geoffrey Huntley's post “Ralph Wiggum as a ‘software engineer’” (July 2025, ghuntley.com/ralph): in its purest form, a Ralph loop is a Bash loop that starts a coding agent again and again with the same prompt.
  • It's named after Ralph Wiggum from The Simpsons: well-meaning, but maybe not all that bright. Each time round, a new agent session wakes up, looks at the plan, does the next step, ticks it off and goes back to sleep. No single session has to think very hard.
  • Matt told this in September's session 1, at 02:12:22. Use his telling as a guide.
  • “A Ralph loop is the smallest software factory there is. The factory you'll build grows from it.” Hand to David.

An assembly line is machines in an order, fixed by whoever designed it. A machine is an agent that's handed its inputs and runs to completion, with no person in the conversation.
